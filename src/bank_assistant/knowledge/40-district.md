# District demographic data

## district.A2_A3: district name and region
The district table has anonymised column names. district_id identifies the district.
A2 = district name (e.g. 'Hl.m. Praha', 'Pisek', 'Sokolov', 'Jesenik'). A3 = region, one of
'Prague', 'central Bohemia', 'south Bohemia', 'west Bohemia', 'north Bohemia', 'east Bohemia',
'south Moravia', 'north Moravia' (written in lowercase except Prague).

## district.A4_A10: population and municipalities
A4 = number of inhabitants. A5 = number of municipalities with fewer than 499 inhabitants,
A6 = with 500-1999, A7 = with 2000-9999, A8 = with 10000 or more inhabitants.
A9 = number of cities. A10 = ratio of urban inhabitants (percent).

## district.A11: average salary
A11 = average salary in the district.

## district.A12_A13: unemployment rate
A12 = unemployment rate in 1995 (percent). A13 = unemployment rate in 1996 (percent).
One district has no 1995 value (NULL).

## district.A14: entrepreneurs
A14 = number of entrepreneurs per 1000 inhabitants.

## district.A15_A16: committed crimes
A15 = number of committed crimes in 1995. A16 = number of committed crimes in 1996.
One district has no 1995 value (NULL).
